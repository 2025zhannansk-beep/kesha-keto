# ТЕХНИЧЕСКОЕ ЗАДАНИЕ: КотоКеша

## 1. КОНТЕКСТ
**Продукт:** «КотоКеша» — PWA для персонализированного кето-питания.
**Идея:** Пользователь загружает анализы (вручную или фото/PDF) → получает рекомендации → формирует меню из своей «Кладовой» → общается с ИИ-помощником Котом Кешей.
**Платформа:** PWA (Next.js), адаптированное под мобильные экраны.

## 2. СТЕК ТЕХНОЛОГИЙ
- **Frontend:** Next.js 14 (App Router) + TypeScript + Tailwind CSS
- **UI:** shadcn/ui
- **Backend/DB:** Supabase (PostgreSQL + Auth + Storage + RLS)
- **AI:** OpenAI API (gpt-4o-mini для чата, gpt-4o Vision для распознавания фото)
- **Хостинг:** Vercel

## 3. ДИЗАЙН-ФИЛОСОФИЯ (CALM UX)
Приложение воплощает "кошачью мудрость": спокойствие, плавность, уют, отсутствие суеты.
- **Фон:** Теплый кремовый (`#FDFBF7`)
- **Акценты:** Мягкий шалфейный зеленый (`#4ade80`), приглушенный персиковый (`#FDBA74`)
- **Текст:** Теплый серый (`#44403C`), НЕ черный.
- **Формы:** Большие скругления (`rounded-2xl` или `rounded-3xl`), мягкие тени.
- **Предупреждения:** Мягкий терракотовый/оранжевый. Никакого агрессивного красного!
- **Шрифт:** Nunito (округлый, дружелюбный).

## 4. МОДЕЛЬ МОНЕТИЗАЦИИ
- **Free:** 0 ₽. Ввод 2 биомаркеров, кладовая до 5 продуктов, Кеша — 3 вопроса/день.
- **Кеша Pro:** 990 ₽/мес. Полный ввод, персонализация, безлимитная кладовая, генератор меню, безлимитный Кеша, модуль «Прогресс».
- **Путь к стройности:** 7 900 ₽ разово. 21-дневный интенсив с заданиями.

## 5. КЛЮЧЕВЫЕ МОДУЛИ (User Stories)
1. **Онбординг:** Регистрация, 5 карточек о кето, анкета здоровья.
2. **Лаборатория:** Ручной ввод 5 биомаркеров + загрузка фото/PDF с распознаванием через GPT-4o Vision.
3. **Персонализация:** Движок правил ЕСЛИ→ТО, генерирующий карточки рекомендаций.
4. **Кладовая и Меню:** Отметка наличия продуктов, генерация меню на 3 дня из имеющегося, список покупок только для недостающего.
5. **Прогресс:** Еженедельный ввод веса, обхватов (грудь, талия, бедра) и самочувствия (6 шкал 1-5 с эмодзи). Графики и индекс "Кето-побед".
6. **Кеша:** Чат-бот с полным контекстом профиля, анализов и кладовой.

## 6. КРИТЕРИИ ПРИЕМКИ MVP
- PWA устанавливается на главный экран.
- Загрузка фото анализа распознает данные с точностью > 90%.
- Меню генерируется с учетом продуктов в кладовой.
- Кеша отвечает в заданном "кошачьем", спокойном тоне.
- Время загрузки экрана < 2 сек.
